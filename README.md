# React E-commerce Shopping Application

## Project Description

Cartly is a simple e-commerce shopping application. Users can browse products fetched from a public API, search and filter them, open a product details page, and manage a shopping cart. The cart is managed globally with Redux Toolkit.








## Installation Instructions

Make sure Node.js and npm are installed.

git clone <repository-url>
cd react-ecommerce-assignment
npm install


## How to Run the Project


npm run dev       # start the development server (http://localhost:5173)
npm run build     # create a production build in dist/
npm run preview   # preview the production build locally
